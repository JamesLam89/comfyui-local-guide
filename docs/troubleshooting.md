# 常见问题

[返回教程首页](../README.md)

## 缺失模型

先看报错节点需要的完整文件名及模型类别，再检查文件是否放进当前运行实例所使用的 `models` 目录。主模型、文本编码器、VAE 和 LoRA 分别属于不同类别。工作流引用 BF16，而本机装了 INT8 时，应在加载节点选择兼容的量化文件，不能通过重命名假装安装了另一版本。

## 缺失节点

记录报错里的节点类型，按工作流或节点作者说明安装对应包。包文件存在不代表导入成功；还需要查看启动日志中的依赖错误。安装依赖时使用运行 ComfyUI 的 Python 环境。更新或重启前先等当前队列完成。

## 文件已下载，网页仍显示缺失

确认浏览器连接的是正确端口和实例。刷新模型列表或页面；仍异常时查看后端实际暴露的模型与节点。不要因为旧页面的告警而重复下载多份大文件。

## 8GB 显存不够

从单张、小分辨率开始，关闭占用显存的其他程序，并按安装方式配置低显存运行选项。卸载到系统内存会降低速度，也会增加 RAM 需求。磁盘上的 6GB 权重不意味着整个流程只需要 6GB 显存。

## 加了加速 LoRA 却没变快或画质变差

核对底模家族、LoRA 版本、步数、CFG 和 sigma / sampler。5 步、6 步、8 步通常是不同训练和采样路线，不能随意互换。先只测试一个加速 LoRA，再固定种子比较结果。

## 参考图没有原样保留

参考图条件生成与传统 latent 图生图的行为不同。先看图像进入的是文本/视觉编码节点，还是 VAE 编码后的起始 latent。需要保真修复时，选择针对修复训练的模型或工作流，并测试身份和构图是否发生变化。

## 分享前检查什么

工作流中的上传图片名称、绝对路径、服务地址和访问凭据，以及 PNG 中的提示词和工作流元数据，都可能包含私人信息。发布你实际准备分享的文件即可；本地浏览器备份、模型权重和运行日志无需随教程上传。
